# 🔥 This Is Fine: The Game

A frantic, Flutter-based arcade game inspired by the iconic "This is Fine" meme. Navigate the chaos, manage your panic levels, and survive as long as possible before you get "crisped."

<br>

## 🚀 Features

### 🎮 Dual Game Modes

Fine Mode: The classic experience, offering the game in a much relaxing vibe, extinguishing fire, and occasionally drinking coffee.

Stressed Mode: For the brave. With much amped up difficulty, fire spawning duration cut short by half, coffee only starts appearing when panic bar reaches 65% or more with a lower spawn rate.

<br>

## 🕹️ How to Play

Extinguish Fires: Tap the fire icons to lower your panic bar.

Drink Coffee: When coffee appears, grab it and give it to the dog character to stop panic growth temporarily and gain a score bonus.

Survive: If the panic bar reaches 100%, the game is over.

Pause & Restart: Use the top-right button to pause, but remember: there's no resting, only restart.

<br>

## 🎯 Scoring :

Score is gained overtime by how long a player can survive in this game, counted up per second (meaning playing on 'Stressed' mode will need to work twice harder to gain the same score on 'Fine' mode)

Coffee gives bonus score of 3 for every consume, this mechanic works the same on both modes to not confuse players too much.
